Database backup

Download or restore Matrix-Art runtime data. Backups include artwork, frames, folders, page settings, animation settings, Code effects, demos, and saved Wi-Fi entries stored in the database.

The Settings PIN and session secret are not included in backups. Restoring a backup keeps the current device PIN.
