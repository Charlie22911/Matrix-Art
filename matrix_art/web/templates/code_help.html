How to write Python effects for the 64×64 RGB matrix.

Back to Code Library Settings

Minimum effect

Each code effect is a Python script. The only required function is render(). Matrix-Art calls it repeatedly and sends the resulting 64×64 RGB frame to the panel.

def render(ctx, t, dt, frame, params):
    frame.fill(0, 0, 0)
    frame.set_pixel(32, 32, 255, 0, 0)

Function arguments

  • ctx contains display and timing values.
  • t is seconds since the effect started.
  • dt is seconds since the last frame.
  • frame is the 64×64 drawing buffer.
  • params contains default parameter values from PARAMS.
  • state is optional persistent storage returned by setup().
def setup(ctx):
    return {"x": 0, "direction": 1}

def render(ctx, t, dt, frame, params, state):
    state["x"] += state["direction"]
    if state["x"] <= 0 or state["x"] >= ctx.width - 1:
        state["direction"] *= -1
    frame.fill(0, 0, 0)
    frame.set_pixel(state["x"], 32, 0, 255, 80)

Context values

  • ctx.width and ctx.height are normally 64.
  • ctx.fps is the target frame rate.
  • ctx.frame_index starts at 0 and increments each rendered frame.
  • ctx.time and ctx.dt mirror t and dt.

Frame drawing helpers

  • frame.fill(r, g, b)
  • frame.clear()
  • frame.set_pixel(x, y, r, g, b)
  • frame.get_pixel(x, y)
  • frame.fade(amount), where 1.0 keeps everything and 0.0 fades to black
  • frame.line(x0, y0, x1, y1, r, g, b)
  • frame.rect(x, y, w, h, r, g, b, fill=False)
  • frame.circle(cx, cy, radius, r, g, b, fill=False)

Parameters

Effects may define PARAMS. At the moment Matrix-Art uses the default values. Slider controls can be added later without changing the effect format.

PARAMS = {
    "speed": {"type": "float", "default": 1.0, "min": 0.1, "max": 4.0, "step": 0.1},
    "count": {"type": "int", "default": 12, "min": 1, "max": 50, "step": 1},
}

Tips

  • Keep nested loops small. The panel is only 4,096 pixels, so full-screen loops are fine.
  • Use dt for movement so the effect speed stays stable if FPS changes.
  • Use setup() for persistent objects such as stars, particles, balls, grids, or random seeds.
  • Keep imports simple. Built-in modules like math and random work well.
  • Run Editor lets you test unsaved changes. Save stores the code and updates its Library thumbnail from frame 10.
